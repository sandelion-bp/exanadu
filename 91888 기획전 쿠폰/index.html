91888 기획전 전용 할인쿠폰

초안 최종 수정: 2026-10-01 원본: Obsidian Vault PRD (스냅샷, 자동 동기화 아님)

배경 및 문제

운영

  • 쿠폰 적용 대상은 상품·카테고리 단위로 설정 가능하여, 기획전 상품에 쿠폰을 제공하려면 상품 개별 등록 필요
  • 기획전 상품 추가·제외 시 쿠폰 대상도 별도 수정 → 변경 누락·오등록 가능성 존재

시스템 무결성

  • 기획전 쿠폰 영역을 이미지·링크 기반으로 수작업 구성
  • 쿠폰 설정과 고객 화면을 별도로 관리하여 정보 불일치 가능성 존재
  • 기획전 상품 변경·종료에 따른 쿠폰 처리 기준 필요

요구사항

  1. 중요 쿠폰 적용 범위 추가 : 상품, 카테고리 → 상품, 카테고리, 기획전(추가)
    • 쿠폰은 적용대상으로 기획전 1개만 설정 가능
    • 한 기획전에는 최대 6개의 쿠폰이 적용될 수 있음
  2. 중요 쿠폰 다운로드 : 사용자는 쿠폰을 개별 또는 한번에 전체를 다운로드 할 수 있음
  3. 중요 기획전 상품 변경 및 쿠폰 적용 대상 변경 시 변경사항 즉시 반영
  4. 중요 상품 구매 시 쿠폰 적용 기준 : 상품 쿠폰 > 기획전 쿠폰 > 카테고리 쿠폰 순
  5. 고객사 유저 단위로 기획전 쿠폰 다운로드 버튼을 노출
  6. 기획전 관리에서는 쿠폰 자체 정보 조회 및 쿠폰 관리 상세 이동 제공
  7. 기획전에 노출될 쿠폰 정보를 현업에서 수기 입력 가능

유저플로우

유저 : 기획전 페이지 진입 → 쿠폰 다운로드 버튼 확인(노출대상 여부 고려) → 버튼 클릭 → 알럿 확인

검토 및 추가 고려사항

  • 적용대상 추가 시 고려해야 하는 로직 및 페이지? (예: 상품상세)
  • 기획전 상품이 변경될 경우, 쿠폰 대상에 즉각 반영되는지?
