기획전 전용 할인쿠폰 기능 개발요청

초안 최종 수정 2026-10-02 · 원본 : Obsidian Vault PRD (스냅샷, 자동 동기화 아님)
배경 및 문제 요구사항 정책 유저플로우 검토 및 추가 고려사항 화면설계
01

배경 및 문제

운영
  • 쿠폰 적용 대상은 상품·카테고리 단위로 설정 가능하여, 기획전 상품에 쿠폰을 제공하려면 상품 개별 등록 필요
  • 기획전 상품 추가·제외 시 쿠폰 대상도 별도 수정 → 변경 누락·오등록 가능성 존재
시스템
  • 기획전 쿠폰 영역을 이미지·링크 기반으로 수작업 구성
  • 쿠폰 설정과 고객 화면을 별도로 관리하여 정보 불일치 가능성 존재
  • 기획전 상품 변경·종료에 따른 쿠폰 처리 기준 필요
02

요구사항

중요 4건 / 전체 7건
  1. 중요쿠폰 적용 범위 추가 : 상품, 카테고리 → 상품, 카테고리, 기획전(추가)
    • 쿠폰은 적용대상으로 기획전 1개만 설정 가능
    • 한 기획전에는 최대 6개의 쿠폰이 적용될 수 있음
  2. 중요쿠폰 다운로드 : 사용자는 쿠폰을 개별 또는 한번에 전체를 다운로드 할 수 있음
  3. 중요기획전 상품 변경 및 쿠폰 적용 대상 변경 시 변경사항 즉시 반영
  4. 중요상품 구매 시 쿠폰 적용 기준 : 상품 쿠폰 > 기획전 쿠폰 > 카테고리 쿠폰 순
  5. 고객사 유저 단위로 기획전 쿠폰 다운로드 버튼을 노출PRM팀
  6. 기획전 관리에서는 쿠폰 자체 정보 조회 및 쿠폰 관리 상세 이동 제공
  7. 기획전에 노출될 쿠폰 정보를 현업에서 수기 입력 가능 (타이틀, 내용, 색상)
03

정책

  • 쿠폰 발행·유효기간과 기획전 사용/전시기간을 연동하지 않음
  • 기 발급된 쿠폰은 기획전과 관계없이 유효기간까지 사용
  • 기획전 쿠폰은 상품 상세 쿠폰다운로드에 적용되지 않음
  • 쿠폰 적용 후 결제 승인 직전 쿠폰 유효 여부 검증 (쿠폰 적용 대상이 맞는지)
  • 고객사 판정 : 기획전 적용고객사 ∩ 쿠폰 적용고객사의 교집합으로 노출·발급 대상 판정
  • 쿠폰 상태와 관계없이 최대 6개를 한 기획전에 적용 가능

05

검토 및 추가 고려사항

확정 2 · 방향 1 · 미결 3
확정

쿠폰 기간과 기획전 기간은 독립

  • 쿠폰 발행·유효기간과 기획전 전시기간을 강제로 연동하지 않음
    • 쿠폰에서 적용대상으로 기획전을 지정하는 구조라, 기획전에 묶였다고 기간까지 종속시키면 안 됨
    • 기획전 등록 후에도 쿠폰 기간을 며칠로 고정해야 하는 운영 케이스가 있음
  • 기획전이 종료·전시중단돼도 쿠폰을 자동 제거·중지하지 않음
    • 운영 실수로 내린 것일 수 있고, 내렸던 기획전을 다시 살려 쓰는 사례가 실제로 있음
  • 발행된 쿠폰은 유효기간까지 사용 가능
확정

고객사 판정

  • 기획전 적용고객사 ∩ 쿠폰 적용고객사의 교집합으로 노출·발급 대상 판정
  • 보완 검토 : BO 저장 시 두 설정이 어긋나면 경고 노출 (저장은 허용하되 알림)
방향

적용 우선순위 — 요구사항 4 현업 조정 필요

  • 사용자 관점 기준 : 할인액이 큰 쿠폰 우선 → 만료가 임박한 쿠폰 우선
  • 정률 쿠폰은 주문금액 기준으로 계산한 실제 할인액으로 비교
  • 요구사항 4(상품 > 기획전 > 카테고리)는 쿠폰 종류 순서라 위 기준과 충돌
    • 예 : 상품 쿠폰 1,000원 vs 기획전 쿠폰 5,000원 → 요구사항 4면 상품 쿠폰, 할인액 기준이면 기획전 쿠폰
제안 · 할인액 최대(1순위) → 만료 임박(2순위) → 요구사항 4의 종류 순서(동률 시 타이브레이커)
제안 · 자동 적용은 추천값으로 두고 고객이 다른 쿠폰으로 변경 가능하게 (커머스 표준)
미결

결정 필요

  1. 기획전당 쿠폰 최대 6개의 카운트 기준
    발행중만 / 발행중+발행대기 / 종료·중지 포함 중 선택
    제안 · 발행중 + 발행대기만. 종료분까지 세면 지난 쿠폰이 자리를 막아 운영이 멈춤
  2. 한 상품이 여러 기획전에 속할 때 기획전 쿠폰 간 순서
    쿠폰은 기획전 1개만 지정하지만 상품은 기획전 중복 노출이 가능
    요구사항 4에 기획전끼리의 순서는 없음 → 위 할인액 기준으로 흡수 가능한지 확인 필요
  3. 노출 문구 수기 입력과 실제 쿠폰값 불일치
    완전 차단은 불가 — 문구에 20% 할인, 실제 쿠폰 10%여도 막을 장치 없음
    배경의 “쿠폰 설정과 고객 화면 별도 관리 → 정보 불일치” 문제가 재발하는 구조
