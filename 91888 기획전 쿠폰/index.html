참고용
기존 관리자페이지 쿠폰관리 화면을 HTML/CSS로 그대로 재현 + 동작 유추 적용 새 창에서 보기 ↗

화면 설명

  1. ① 이 화면은 91888 신규 기능의 목표 화면이 아니라, 기존 쿠폰관리 화면을 그대로 재현한 AS-IS 참고본이다. 기획전 전용 쿠폰 기능은 이 화면을 기반으로 별도 화면(SCR-02~)에서 설계한다.
  2. ② 발행횟수제한·쿠폰 총발급 수량·적용유효기간의 라디오는 선택된 쪽 입력만 활성화되도록 유추 구현했다.
  3. ③ 적용고객사의 전체/적용/제외 라디오에서 "전체"를 고르면 하단 고객사 목록·추가/삭제 버튼이 비활성화되도록 유추 구현했다.
  4. ④ 추가·검색 버튼의 팝업 목록은 실제 데이터 연동 없이 데모용 더미 값이다.
  5. ⑤ 쿠폰발행/저장/취소는 서버 연동 없이 화면 동작만 흉내 낸 것이다(토스트 메시지로 표시).
확인 필요 (원본 스크린샷에서 유추한 부분) 할인유형(정액/정률)에 따라 적용조건의 단위(원/%) 표시가 실제로 전환되는지, 적용범위(마스터카테고리/상품)를 선택했을 때 하단에 별도 선택 UI가 나타나는지, 쿠폰발행 및 현황 탭의 실제 구성은 스크린샷에 없어 확인하지 못했다.
